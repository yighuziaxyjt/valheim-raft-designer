## Overview

Valheim RAFT Ship Designer is a companion web tool for the RAFT Valheim mod that provides a drag-and-drop ship layout canvas where players plan their vessel structure before building in-game, calculates total material requirements for the planned hull and decking, estimates weight and stability, and displays sail area coverage.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Valheim RAFT Ship Designer** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Layout Canvas** | Drag-and-drop ship block placement on a grid canvas |
| **Material Calculator** | Calculates total wood, iron, and other materials for the build |
| **Stability Estimate** | Estimates ship stability based on hull width and height ratio |
| **Sail Coverage** | Visualizes sail placement and calculates total sail area for speed |
